ABHINAV SUBEDI — PHOTOGRAPHY PORTFOLIO

FOLDERS
images/nature/   -> Nature photographs
images/street/   -> Street photographs
images/portrait/ -> Portrait photographs

HOW TO ADD PHOTOS
Just drag your photos into the correct folder and upload/commit them to GitHub.
You do not need to edit index.html. The gallery automatically reads the public GitHub folders.

GITHUB PAGES
Repository: Accalus/Abhinav-Portfilio-Photography
Branch: main
Pages source: Deploy from a branch -> main -> / (root)

After committing new photos, give GitHub Pages a little time to redeploy, then refresh the site.

The site uses a GitHub Contents API request to discover image files. If the API is temporarily unavailable, the existing local photos are used as a fallback.
